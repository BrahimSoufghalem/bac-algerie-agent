# مَسار — وكيل البكالوريا الجزائرية

منصّة تعليمية عربية بمحادثة أولًا، ووكيل تدريس واحد يستخدم مراجع المالك سرًا. إعادة استخدام مستقلة لمحرك BookForge؛ لا تُغيّر مشروعه الأصلي.

## السياسة الحالية: مراجع سرية ووكيل مستقل

- **لا مكتبة للطالب أو الأستاذ**: ملفات المالك المعتمدة سياق داخلي للوكيل فقط. الخادم يمنع مسارات النصوص والصفحات والصور والفهارس حتى بمعرّف معروف، لا مجرد إخفاء زر.
- يستطيع الوكيل فحص الصورة الأصلية داخليًا لفهمها، لكنه لا يعرضها أو يربطها. لا استشهادات تكشف أسماء الملفات أو صفحاتها أو معرّفاتها. الرسوم المحسوبة الجديدة تُسمّى بوضوح ولا تُنسب إلى الكتاب.
- درج **مراحل الإجابة** بين سؤال المستخدم والرد، مستقل لكل إجابة ومحفوظ عند إعادة فتح المحادثة. يعرض ملخّص تقدّم وتنفيذ ثابتًا من أحداث الخادم، **لا التفكير الداخلي** ولا أسماء الأدوات أو مدخلاتها أو نتائجها أو تفاصيل المراجع. السجلات التقنية تبقى داخل الخادم؛ SSE والتصدير ينقلان الملخّص المُنقّى فقط.
- حُذفت مساحة التدريب الذاتي وأداتها وسجلاتها القديمة. تحضير الأستاذ الخاص يبقى للأستاذ والمالك فقط.
- **ملاحظات مسار التعليمية** داخل إعدادات الحساب، للقراءة فقط. يكتبها أو يصححها الوكيل بناءً على دليل تعلّم، لا بأمر من الطالب لتلفيق الإتقان. الملاحظات اليدوية القديمة لا تدخل ذاكرة الوكيل.
- لا حد ثابت لجولات النموذج أو عدد الأدوات الكلي؛ إعداد `MAX_RUN_STEPS` القديم مُهمَل. تبقى مهلة الوقت والسياق وحجم النتائج وحدود الحساب ومكافحة التكرار وزر الإيقاف لحماية الرصيد والخدمة.
- أُلغيت مفاتيح وصول الوكلاء الخارجيين إلى المراجع. مراجعة المصادر وإدارتها تتطلب حساب المالك؛ عامل التدريس يقرأها داخليًا مباشرة.

**تحديث ذو تغييرات غير متوافقة:** migration006 يسحب service tokens ويحذف سجلات self_practice. خذ نسخة احتياطية كاملة قبل التحديث، وحدّث **API وworker معًا**. لا تحذف مجلد البيانات أو Docker volume.

اختبارات محلية ونموذج فعلي موثّقة في [تقرير الخصوصية والمحادثة المستقلة](docs/acceptance/private-autonomous-chat.md). ليست شهادة أمنية أو ضمانًا لدقة كل شرح أو نشرًا على جهاز المستخدم. [التشغيل](docs/OPERATIONS.md) · [الاسترجاع الداخلي](docs/RETRIEVAL.md) · [التعلّم والخصوصية](docs/LEARNING.md) · [الحساب العلمي](docs/SCIENCE.md).

تحسين الدرج والشريط والإعدادات والمرفقات موثّق في [تقرير واجهة المراحل المحفوظة](docs/acceptance/per-answer-work-ui.md). هذا التحديث لا يضيف migration ولا يجري اختبار مزوّد مدفوعًا جديدًا.

## تشغيل محلي

يتطلب Python 3.13 وNode 24. جميع الأوامر من جذر المشروع.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt -c constraints.txt
npm ci
npm run build
cp .env.example .env
python -m bac.cli bootstrap --email YOUR_OWNER_EMAIL --name 'المالك'
# سيطلب كلمة مرور 12 حرفًا أو أكثر دون إظهارها.
uvicorn bac.api.main:create_app --factory --host 127.0.0.1 --port 8090
```

في طرفية ثانية، بنفس البيئة والمجلد:

```bash
source .venv/bin/activate
python -m bac.worker
```

افتح **http://127.0.0.1:8090**. لا تُدخِل مفتاح التطبيق القديم BookForge؛ هنا حساب مستقل بكلمة مرور. من «إعداد النماذج» احفظ Base URL واسم النموذج والمفتاح لكل من **التدريس** و**الاستخراج**. الحفظ لا يرسل طلبًا مدفوعًا. التدريس يتطلب نموذجًا متوافقًا مع أدوات Chat Completions؛ الاستخراج يتطلب Vision. قيم النموذج الافتراضية أمثلة فقط. الاختبار الفعلي الأخير استخدم مزودًا يدعم Chat Completions؛ لا ضمان لتوافق أي اسم نموذج آخر.

رفع ← معاينة ← بدء المعالجة ← مراجعة تحذيرات وصور المصدر ← اعتماد المراجعة ← تفعيل للوكيل. للامتحان أو سلسلة التمارين أرفق الحل إن وجد وأكد مطابقته قبل الاعتماد؛ يمكن تركه مفقودًا صراحة. لتغيير مصدر معتمد اضغط «إنشاء نسخة جديدة»، ثم أعد المراجعة. المصادر المسودة لا تصل إلى الوكيل، والمراجع المعتمدة لا تصل إلى الطالب مباشرة أيضًا. إنشاء الحساب العام ينتج **طالبًا فقط**؛ لا يمكن اختيار owner أو teacher من المتصفح. الحسابات الجديدة ليست تحققًا من البريد الإلكتروني بعد.

### فتحه مرة ثانية والنتائج

شغّل خدمتي API وworker بالأوامر نفسها، ثم افتح العنوان نفسه. أغلق المتصفح دون إيقاف الخادم إن أردت استمرار المعالجة. إيقاف الكمبيوتر يوقف العمل، لكنه يحفظ الحالة. محرك استخراج الكتب يستأنف وظائفه من قاعدة البيانات ولا يعيد الصفحات الناجحة. تشغيل دردشة مدفوع انقطع أثناء التنفيذ يُعلَّم `INTERRUPTED` بدل إعادة طلبه تلقائيًا وإضافة تكلفة غير معلنة؛ يمكن للطالب إعادة المحاولة صراحة.

```text
data/
├── platform.sqlite3          # الحسابات، النسخ المنشورة، المحادثات، تشغيلات الوكيل والاستخدام
├── .encryption.key              # مفتاح التشفير المحلي؛ احتفظ به مع النسخ الاحتياطية
├── extraction/
│   ├── state.sqlite3         # طابور الكتب، الصفحات، retries وleases
│   └── library/<raw-book>/   # الأصل PDF، الصفحات، JSON، Markdown، الصور والهيكل
├── private/<upload-id>/      # ملفات محادثة خاصة مؤقتة، لا تدخل المكتبة، TTL 24 ساعة
└── snapshots/<version>/<review>/
    ├── manifest.json        # provenance + تحذيرات الجودة + العقد والعناصر
    ├── nodes/<node>/content.md
    ├── parts/*.md           # أجزاء ثابتة للدروس الطويلة فقط
    └── files/{primary,solution}/
        ├── source.pdf       # نسخة مستقلة من المصدر الكامل
        ├── content.md       # كامل نطاق الملف المنشور دون تلخيص
        ├── assets/*.png
        └── pages/*.{png,json,md} # الصفحات وJSON وMarkdown المعتمدة
```

اسم مفتاح vault الحقيقي موثّق في `bac/vendor/bookforge/core/secrets.py`؛ لا تعِد توليده عند النقل. لا تنقل هذه البيانات إلى Git. استخدم نسخة احتياطية متناسقة للـ DB والملفات والمفتاح؛ أوقف الخدمتين قبل نسخ كامل المجلد في هذه النسخة الأولى. SQLite على قرص محلي، لا NFS. نشر نسخة جديدة يبدل مؤشر النسخة الحالية ذريًا؛ لا يغير ملفات النسخة القديمة. إلغاء النشر بالأرشفة يمنع الوصول حتى لو سبق تحميل المحتوى في cache.

### Docker

```bash
cp .env.example .env
docker compose up --build -d
docker compose run --rm api python -m bac.cli bootstrap --email YOUR_OWNER_EMAIL
# لاحقًا:
docker compose up -d
# لتحديث نسخة موجودة، بعد النسخ الاحتياطي المذكور في OPERATIONS.md:
git pull --ff-only
docker compose up -d --build api worker
```

وصفة Docker مُضافة لكن لم تُبنَ داخل بيئة التطوير التي لا تحتوي Docker. المنفذ مرتبط بـ localhost افتراضيًا. للنشر العام: HTTPS/reverse proxy، `SECURE_COOKIES=true`، سياسة تسجيل/نسخ احتياطي، حدود موارد ومراقبة واختبار أمني. **لا تعرّض النسخة الحالية للعامة بوصفها منتجًا نهائيًا.**

## كيف يصل الوكيل إلى المراجع؟

يستخدم عامل التدريس أدوات داخلية للبحث وقراءة العقد أو أجزاء الدروس الكاملة. snippets محددات مكان وليست قراءة مرجع كامل. الامتحان وحلّه المرفق وسلسلة التمارين حزم منطقية لا تُبتر. عناوين المراجع و`source_ids` للاتساق الداخلي فقط.

مسارات `/api/library/*` و`/api/agent/*` تتطلب مالكًا مصادقًا؛ ترجع 404 للطالب والأستاذ. Bearer/service tokens السابقة ملغاة. `/api/science/*` و`/api/openapi.json` غير متاحة في التطبيق العام. لا تمنح الطلاب ملفات المصدر أو حساب المالك أو مجلد البيانات.

الجواب الظاهر: text، equation، table، code للعرض، ورسوم مولّدة من بيانات حسابية فعلية. كتل الصور الأصلية والتحقق التقني ممنوعة من العرض. التحقق الحسابي يخص المدخلات المحددة، لا يصادق على فهم السؤال أو كل التفسير. منع النسخ الحرفي الطويل إجراء إضافي محدود، وليس برهانًا على استحالة تسريب معلومات دلالية من نموذج يرى المرجع.

### شرح الدروس مشروط بقراءة فعلية

لا يكفي البحث أو الاعتماد على ذاكرة النموذج. يمنع الخادم إنهاء شرح الدرس دون اختيار مرجع قُرئ وأُرسل فعليًا إلى سياق التشغيل. غياب المرجع المناسب يستلزم سؤالًا توضيحيًا قصيرًا؛ التحية والحساب العددي المباشر مساران منفصلان. إعادة المحاولة تعيد التحقق من المرجع وتُظهر القراءة الفعلية دون اختلاق مراحل، وتحتفظ بالمحاولة السابقة. هذا شرط قراءة واتساق، وليس برهانًا على صحة كل جملة أو ملاءمة المرجع تلقائيًا. راجع [اختبار القراءة والتعافي من الأخطاء](docs/acceptance/grounded-teaching-recovery.md).

## حدود وتكلفة التشغيل

- نموذج تدريس واحد لكل تشغيل، بلا subagents وبلا ChatGPT/Kilo لإدارة التطبيق.
- طابور محفوظ في SQLite، claim ذرّي، fencing token، heartbeat وحدود وقت وحجم سياق ونتائج، دون عدد ثابت للجولات.
- محرك Vision: صفحة ناجحة لا تعاد، أخطاء مؤقتة retry/backoff، صفحة مشكوك فيها تبقى صريحة ولا تُوقف الكتاب.
- التدريس: لا retries خفية لطلب مدفوع، ولا تكلفة مفترضة. الأسعار اختيارية في API ModelConfig؛ عند غيابها cost = null.
- `input_tokens` و`output_tokens` و`cached_tokens` تحفظ فقط إذا أبلغ المزوّد عنها. لا نسب cache وهمية.
- حد context في هذه المرحلة **بالحروف**، وليس عدّاد tokens دقيقًا لكل مزود. محتوى زائد يُرفض مع طلب قسم/جزء أصغر للكتب، أو زيادة الميزانية للحزمة الذرّية؛ لا بتر ولا تقسيم مصطنع للامتحان.
- SSE ينقل ملخّص مراحل العمل العام والجواب النهائي المُنقَّى والخطأ العام. لا نصوص نموذج وسيطة أو تفاصيل أدوات؛ تظهر blocks بعد اكتمال JSON والتحقق منه. هذا يمنع عرض معلومات المرجع خلال البث قبل فحص الجواب.
- مزوّد Chat Completions يجب أن يدعم tools وstream. لا يوجد fallback مدفوع تلقائي إذا رفض `stream_options` أو JSON schemas.
- PDF ونص الكتاب مدخلات غير موثوقة، لا تعليمات أو كود قابل للتنفيذ.

## الاختبارات

```bash
pytest -q
npm run build
npx playwright install chromium
npm run test:browser
```

اختبارات التكامل تستخدم مزودًا وهميًا معلنًا فقط داخل `tests/browser/server.py`، وهو ليس entry point للنشر. تستخدم فعليًا رفع PDF ممسوح اصطناعي متعدد اللغات، محرك render/crop/Markdown والـ queue والنشر وأدوات الاسترجاع وSSE. لا تدّعي هذه الاختبارات جودة Vision حقيقي أو أداء آلاف الطلاب. قياس فعلي صغير للمزوّد يحتاج إذنًا منفصلًا لتجنب استهلاك رصيد غير لازم.

## واجهة المحادثة الجديدة

الواجهة أعيد بناؤها باتجاه تجربة chat-first: قائمة محادثات قابلة للطي، مربع كتابة عائم، ومظهر فاتح/داكن/تلقائي. لا عرض مصادر للطالب. اضغط **اسم المستخدم أسفل الشريط** للوصول للإعدادات وإدارة المالك؛ ملاحظات الوكيل للقراءة فقط داخل الإعدادات؛ المكتبة والتدريب الذاتي غير موجودين للطالب. انظر [دليل التصميم](docs/DESIGN.md) للتفاعل والوصول وحدود التحقق. الاسترجاع الداخلي يحتفظ بالمحتوى الكامل، لكن وصول المستخدم وعرض المصادر تغيّرا جذريًا.
