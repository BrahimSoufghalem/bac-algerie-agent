# خطة التنفيذ وحدود الإنجاز

هذه مراحل المنصّة التعليمية في الملف المرفق، لا إعادة تسمية مراحل BookForge الأصلية.

- [x] المرحلة 1: حسابات وأدوار + استخراج مصدر + مراجعة ونشر ثابت + محادثة خاصة + أدوات حقيقية + بث ومصادر واستخدام.
- [x] المرحلة 2: امتحان مع حل مؤكد كحزمة واحدة، exercise collection كحزمة واحدة، metadata وتصنيف ومراجعة الملاءمة، أدوات retrieval للحزم.
- [x] المرحلة 3: حسابات عددية/رمزية/وحدات، scientific sandbox محدود بلا شبكة أو filesystem عام، graph blocks مع بيانات تحقق، اختبارات إجابات ورفض الخطر.
- [x] المرحلة 4: سياق الطالب وتفضيلات وملاحظات بموافقة، ملفات مؤقتة خاصة، أدوات الأستاذ، إدارة الحسابات والحدود، cache/قياس/أسعار بواجهة واضحة.
- [ ] قبول المرحلة 5 النهائي (القدرات التشغيلية منفّذة): اختبارات ضغط وموفر فعلي صغير بإذن، security evaluation، restore/backup، service tokens مقيدة، سياسات البريد وكلمات المرور، نشر production موثّق.

## لا نعتبر وجود الجدول/endpoint إنجازًا وظيفيًا

`exam` و`exercise_collection` متاحان فعلًا في المرحلة الثانية مع نشر واستدعاء حزم كامل؛ الحل الرسمي لا يُخترع. نسبة مصدر الحل وتأكيد المطابقة يقدّمهما المالك ويُوثّقان. code block للعرض فقط؛ الأداة العلمية الجديدة تنفّذ subset محدودًا دون Python عام. لا يُنشأ prerequisite أو حل رسمي من التخمين.

## أدوات استرجاع المرحلة الأولى

`search_library` → `get_table_of_contents` → `get_lesson_full` / `get_section` → `search_within_node` → `render_answer`.

حد source provenance يمنع مصدرًا لم يُحمّل وصورة لم تُستدعَ، لكنه لا يحل وحده مشكلة الهلوسة العلمية. التقييم والتحقق المستقل مطلوبان قبل تسمية المنصة كاملة جاهزة للإنتاج.

## المرحلة الثانية
راجع [عقد الاستدعاء](RETRIEVAL.md): metadata/TOC، درس قصير كامل أو أجزاء عناصر كاملة، حزم ذرّية، IDs للنسخة والملف، sources credit بعد دخول السياق الفعلي، PDF/JSON ثابتان ومعاينة معتمدة.

## المرحلة الثالثة
[عقد الحساب والتحقق والرسم](SCIENCE.md): نتائج علمية فعلية خاصة بالمحادثة، process/resource/AST limits، شارات لا يختلقها النموذج، رسوم آمنة ومخططات متساوية المقياس. المراجعة البصرية للمراحل 2–4 معلقة بسبب عطل أداة العرض؛ لا تسمية production-ready حتى المرحلة 5 وقبول نهائي.

## المرحلة الرابعة
[عقد التعلّم والخصوصية](LEARNING.md): ذاكرة بموافقة وسياق ثابت للتشغيل، ملفات خاصة مؤقتة وصور فعلية للنموذج، مسودات دورية بمقاييس درجات، إدارة حسابات/حدود وأسعار snapshots، قياس actual teaching/Vision وcache مفصول. اكتمال وظيفي باختبارات؛ لا دقة تعليمية أو فواتير نهائية أو جاهزية عامة تلقائية.

## المرحلة الخامسة — تنفيذ واختبارات، لا إطلاق عام تلقائي
[التشغيل والأمان](OPERATIONS.md): استدعاء scoped `/api/agent`، hash/expiry/revoke/document scope، get_lesson كامل أو manifest مع أجزاء بلا اقتطاع، روابط صور قابلة لاستخدام bearer. تغيير كلمات المرور/revoke-all/SMTP encrypted outbox/verification/recovery one-use، قفل maintenance cross-process وbackup/restore فعلي للمصدر والمفاتيح، body-byte caps وhost checks، crash-orphan cleanup، تحميل SQLite/ASGI، إعداد HTTPS/حاوية وفحص Docker في CI. اختبارات موفر mock تحدّد طلبين بلا retry؛ **الفحص المدفوع صفر لأنه حُجب قبل التنفيذ**.
