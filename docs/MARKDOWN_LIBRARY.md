# مكتبة Markdown: التغطية وبيانات التوجيه والحذف

## الرفع والمراجعة

«إدارة المحتوى» تبقى صفحة المالك. اختر المادة، شعبة واحدة أو أكثر، وأحد الأنواع الأربعة (دروس، تمارين، فروض واختبارات، بكالوريا)، ثم ارفع ملفًا أو عدة ملفات `.md` جاهزة بترميز UTF-8، بما فيه UTF-8 BOM. لا نموذج استخراج، ولا OCR، ولا إنشاء صور أو ملخصات جديدة. النموذجان النشطان هما التدريس وراوتر المراجع.

تطبَّق الهوية المختارة على كل الملفات المحددة. كل ملف رئيسي مستند مستقل. ارفع ← عاين النص ومعلومات القسم ← راجع التحذيرات واعتمد ← انشر. لا يدخل المصدر غير المنشور سياق المدرّس. التحذيرات مثل رموز الاستبدال `�` والتكرار في `section_id` لا تصلح بصمت؛ يلزم تأكيد مراجعتها.

لغير الدروس، يمكن أن يكون الحل داخل الموضوع أو يُرفق ملف حل Markdown منفصل عند رفع ملف رئيسي واحد، مع تأكيد المالك أنه يخص الموضوع نفسه. يرث الحل هوية الموضوع، ولا يصبح «حلًا رسميًا» تلقائيًا. الرفع لا يخترع حلًا مفقودًا.

## صيغة بيانات القسم

توضع البيانات **بعد النص الذي تصفه**. مثال اصطناعي، وليس من كتاب المستخدم:

````markdown
# شحن المكثفة

نص الدرس الكامل ومعادلاته وجداوله كما أُعدّت في المصدر.

$$
u_C(t)=E(1-e^{-t/RC})
$$

```yaml
section_id: rc_charge
title: شحن المكثفة
summary: تعريف ثابت الزمن وتطور توتر المكثفة أثناء الشحن
covers:
  - ثابت الزمن
  - شحن المكثفة
status: complete
```
````

`section_id` و`title` و`summary` إلزامية وغير فارغة. `covers` قائمة اختيارية. بيانات `status` وأي حقول إضافية تبقى بيانات مالك، وليست شهادة تحقق من محتوى الدرس.

يدعم المستورد كتل `yaml` أو `yml`، وأسوارًا بلا اسم لغة، وكتلًا غير مسوّرة تبدأ بـ`section_id:`، بما فيها نسيان السور الافتتاحي أو استخدام فواصل `---`. لا تُفسَّر كتل الكود بلغات أخرى كبيانات توجيه. يجب أن تبقى كتلة البيانات واضحة وقابلة لتحليل YAML؛ لا يخمّن المستورد حدود بيانات ملتبسة أو يصلح حقولًا ناقصة.

يُرفض: PDF، الملف غير النصي أو ترميز غير صالح، المصدر الفارغ، كتلة بيانات دون نص سابق، نقص الحقول اللازمة، `covers` غير قائمة، YAML aliases/anchors، أو نص لاحق لم تغطّه كتلة بيانات. القيم والأحجام لها حدود للحماية.

النص الأصلي محفوظ. كتل بيانات التوجيه تُفصل عن جسم الدرس دون تلخيصه. الدروس الطويلة يمكن تقسيمها عند عناوين منطقية فقط؛ لا تقطيع وسط معادلة أو جدول أو برهان/مثال مستقل. إذا تجاوز القسم الذري ميزانية السياق يُرفض تحميله كاملًا بدل بتره. فواصل صفحات المصدر الموجودة تُحفظ؛ عند غيابها يُستخدم مرجع قسم Markdown دون اختلاق صفحة PDF.

## ما يراه الراوتر

لكل مصدر مصرح ومنشور: عنوان القسم، الملخص، `covers`، حجم النص، نوعه وعلاقاته. **لا أجسام الدروس** في الكتالوج. يقدّر الراوتر الملاءمة من هذه البيانات ويسأل عند الغموض؛ لا يضمن كفاية نص لم يره.

يتحقق الخادم من المعرّفات والشعبة والمادة والإصدار والحجم، ثم يقرأ المصدر المختار ويُسلّمه للمدرّس مباشرة. لا طلب دلالي ثانٍ يرسل الدروس إلى نموذج تحقق. المصدر المقروء سابقًا يُعاد تحميله عند الحاجة بعد التحقق من صلاحياته وإصداره، لا لمجرد أنه ظهر في التاريخ.

## جدول التغطية

اختر الشعبة في أعلى الجدول. تظهر **كل مواد المنهج المعرفة**، بما فيها المواد بلا ملفات، مع الأعمدة الأربعة:

- **لم تُضف:** لا ملف رئيسي حالي.
- **بانتظار النشر:** ملفات مرفوعة لكن لا ملف منشور نشط لهذه الشعبة.
- **مضافة:** ملف منشور نشط واحد على الأقل؛ يظهر العدد الكلي وعدد المنشور عند اختلافهما.

العدّ هو عدد **المستندات/الملفات الرئيسية الحالية**؛ ليس عدد الأقسام أو نسخ الملف أو الحلول المرفقة. الملف الواحد المشترك يُعد مرة واحدة في كل شعبة مستهدفة، لا يُنسخ ماديًا لكل شعبة. تغيير نسخة الملف لا يزيد العدد.

## الحذف

زر حذف محتوى المادة يتيح:

- هذه الشعبة فقط، أو جميع الشعب على المنصة.
- نوع محتوى واحد، أو كل محتوى المادة.

المعاينة تعرض عدد المستندات وأسماءها وما سيبقى مشتركًا. لا حذف حتى التأكيد الصريح. يتغير رمز المعاينة عند تغيير النطاق أو المحتوى؛ إضافة ملف بعد المعاينة تمنع تأكيدًا قديمًا. إلغاء النافذة أو اختيار نطاق جديد يبطل الردود القديمة في الواجهة. زر حذف الملف منفردًا يستخدم الحماية نفسها.

حذف المادة من شعبة يعني إزالة **محتواها أو ارتباط ملفاتها**، لا حذف اسمها من المنهج. يبقى الملف المشترك لبقية الشعب، وتبقى المادة ظاهرة بعد إفراغها. الحذف من كل المنصة يسحب الوصول إلى المصدر، يلغي السياقات/التشغيلات المتأثرة ويزيل ملفات Markdown واللقطات المملوكة عبر طابور تنظيف دائم. يُعاد التنظيف عند بدء الخدمة إذا تعثر بسبب النظام/القرص.

الحذف **لا يمس المحادثات السابقة أو النسخ الاحتياطية خارج المكتبة**. ملفات استخراج PDF الخام التاريخية قد تبقى على القرص؛ لا تُحذف تلقائيًا لأن لها قواعد مشاركة قديمة. لا تعني إزالة الوصول محو كل نسخة تاريخية للبيانات.

## الانتقال من نسخة PDF

migration010 يعطّل النموذج النشط لخانة الاستخراج ويضيف طابور التنظيف. لا يمس حسابات التدريس أو الراوتر أو المحادثات أو الكتب تلقائيًا. أزيلت مسارات بدء المعالجة وإعادة استخراج صفحة وإعداد نموذج الاستخراج وعامل الاستخراج من الخدمة النشطة. لا يبدأ تثبيت جديد قاعدة بيانات استخراج.

اللقطات القديمة المنشورة تبقى قابلة للقراءة داخليًا. المسودات القديمة الخام لا تُعالج؛ أعد رفعها بصيغة `.md`. لا تستبدل مجلد البيانات ولا مفاتيح التشفير. خذ backup واختبر الاستعادة ثم حدّث API وworker معًا باستعمال نفس Compose وvolume المستخدمين فعليًا؛ لا `down -v`.

الأدلة التاريخية تحت `docs/acceptance/` تصف إصدارات سابقة، وليست تعليمات لإعادة تشغيل استخراج الكتب. طبقات BookForge المشتركة للتخزين/العقود والتحقق من روابط المزود ما زالت مستخدمة؛ أزيل اتصال محرك استخراج الكتب من التشغيل، لا كل الملفات المورّدة المشتركة.
